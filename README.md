# 🍄 버섯 도그하우스 3D 인터랙티브 뷰어 (Mushroom Doghouse 3D)

제공해주신 3D 실사 렌더링 이미지와 기술 설계 도면(Blueprint)을 기반으로 제작된 **360° 마우스 회전 인터랙티브 3D 동적 웹 애플리케이션**입니다.

---

## 🌐 온라인 라이브 데모 (Vercel 배포)
**바로 접속하기**: **[https://doghouse-3d.vercel.app](https://doghouse-3d.vercel.app)**

별도 설치 없이 모바일, 태블릿, PC 어디서나 웹 브라우저로 3D 버섯 도그하우스와 풍경을 360° 자유롭게 체험할 수 있습니다.

---

## 🚀 로컬 실행 방법

### 방법 1: 더블 클릭 실행 (가장 간편함)
- `run_viewer.bat` 파일을 더블 클릭하면 자동으로 로컬 서버가 시작되고 기본 브라우저에서 3D 뷰어가 열립니다.

### 방법 2: Python 명령어로 실행
```bash
python run_server.py
```
브라우저에서 `http://localhost:8080/index.html`로 자동 연결됩니다.

### 방법 3: 직접 브라우저로 열기
- [index.html](file:///C:/dropbox/antigravity/doghouse/index.html) 파일을 크롬(Chrome)이나 엣지(Edge) 브라우저로 바로 드래그 앤 드롭하여 여셔도 즉시 작동합니다.

## ✨ 주요 기능 및 인터랙션

1. **🖱️ 360° 마우스 드래그 자유 회전 (Turntable & Orbit)**
   - 마우스 좌클릭 후 드래그: 도그하우스를 360도 전 방향으로 부드럽게 회전시킵니다.
   - 마우스 휠 스크롤: 자유로운 줌인 / 줌아웃 확대 축소.
   - 마우스 우클릭 후 드래그: 시점 이동(Pan).
   - 상단 `360° 턴테이블` 버튼: 클릭 시 일정한 속도로 자동 360도 회전 쇼케이스.

2. **🎨 3가지 비주얼 렌더 모드 및 사진 일치 지붕 텍스쳐 매핑**
   - **실사 사진 기반 버섯 갓 지붕 (Photo-Accurate Texture & Bump Mapping)**:
     - 실사 렌더링 사진과 100% 동일한 부드러운 포물선 돔 곡률과 도톰하고 둥근 롤 처마(Rolled Rim) 형태를 정밀 재현.
     - 기존의 기하 도형 부착 방식을 탈피하여 **2048×1024 고해상도 텍스쳐 맵 + 3D 엠보싱 범프 맵(Bump Map)**을 지붕 표면에 일체화 매핑.
     - 사진과 동일하게 배열된 도톰한 크림 화이트 쿠션 반점들과 미세한 가죽 요철 질감이 라이팅 각도에 따라 입체적으로 생생하게 반응.
   - **실사 3D 렌더 모드**: 따뜻한 자연광 정원 조명과 시더우드 원목 루버 질감, 빨간 버섯 갓과 입체 흰색 반점, 폭신한 강아지 방석 침대 재현.
   - **청사진 모드 (Blueprint Mode)**: 도면 스타일의 사이언(Cyan) 형광 와이어프레임과 실제 수치 치수선(`Dome Dia 4'-0"`, `Wall Hgt 3'-6"`, `Base Dia 3'-6"`) 및 부품 명칭 플로팅 핀 표시.
   - **단면 / 투시 모드 (X-Ray Mode)**: 반투명 외벽을 통해 내부 R-19 2인치 단열재 층과 실내 방석 구조 투시.

3. **💥 지붕 분해 조립 (Exploded View)**
   - 좌측 패널의 슬라이더 또는 `지붕 들어올리기` 버튼을 누르면 버섯 갓 지붕이 위로 분해되어 올라가면서 내부 단열재 층과 침실 구조를 시각적으로 검사할 수 있습니다.
   - 표면 텍스쳐 매핑 방식으로 전환되어 지붕 분해 시에도 반점이 들뜨지 않고 완벽하게 일체화되어 작동합니다.

4. **📷 6가지 카메라 프리셋 앵글**
   - 🚪 **정면 출입구**: 아치형 출입구와 디딤판 데크, 실내 방석 정면 시점
   - 🔍 **측면 창문 (Porthole)**: 벽체와 루버를 관통하는 황동 터널 슬리브와 투명 유리를 통해 실내 방석과 따스한 펜던트 램프를 들여다보는 시점
   - 📐 **투시도 (Iso)**: 버섯 하우스 전체가 한눈에 들어오는 3D 아이소메트릭 뷰
   - 🔝 **탑뷰 (지붕)**: 버섯 갓의 도트 패턴과 오버행 직경 시점
   - 🛋️ **실내 방석**: 하우스 내부 아늑한 전용 방석과 조명 시점
   - 📏 **도면 입면도**: 청사진 프론트 엘리베이션(Front Elevation) 2D 정사영 뷰

5. **⚖️ 도면 vs 실사 렌더 인터랙티브 비교 슬라이더**
   - 상단 `도면/렌더 비교` 버튼 클릭 시, 제공해주신 도면과 실사 렌더를 실시간 드래그 슬라이더 커튼으로 오버레이 비교할 수 있습니다.
   - 개별 고화질 탭을 통해 원본 도면 및 원본 렌더링을 전체화면으로 확인 가능합니다.

6. **🌅 조명 환경에 따른 동적 배경 & 대지 풍경 (Sky & Landscape Atmosphere)**
   - **확장된 자연 대지 (Rolling Hills & Forest)**: 도그하우스 주변으로 완만한 잔디 구릉 지형과 24그루의 동화풍 활엽수/침엽수림, 알록달록한 들꽃, 피켓 울타리가 펼쳐집니다.
   - **대기 셰이더 하늘 돔 (Skydome Shader)**: 지평선에서 상공으로 이어지는 부드러운 대기 그라디언트 돔.
   - **천체 & 파티클 시스템**: 태양(Corona Glow), 분화구 달(Moon Glow), 1,200개의 반짝이는 별무리, 부유하는 3D 입체 구름 및 춤추는 반딧불이 무리.
   - **3가지 시간대 전환 (GSAP 1.1s Smooth Interpolation)**:
     - **낮 (Day)**: 맑고 청량한 블루 스카이, 밝은 태양광(1.65), 싱그러운 초록 대지와 숲.
     - **노을 (Sunset)**: 서쪽 지평선으로 낮게 내려앉은 붉은 석양, 핑크/바이올렛빛 노을 하늘, 대지를 가로지르는 긴 노을 그림자, 은은하게 깨어나는 반딧불이.
     - **밤 (Night / 달빛)**: 신비로운 미드나잇 네이비 밤하늘, 은백색 달과 반짝이는 별무리, 숲속을 날아다니는 반딧불이, 꼬마 버섯들의 청록빛 형광 발광, 환하게 켜진 도그하우스 실내등과 포치 정원등, **서정적인 여름밤 귀뚜라미 풀벌레 소리(Web Audio API 절차적 합성)**.

7. **🐶 출입문 앞 귀여운 하얀 강아지 3D 모델 (Live Animation)**
   - 버섯 집 아치형 출입문 앞마당에 둥글둥글하고 사랑스러운 하얀 강아지 모델이 배치되어 있습니다.
   - **디테일한 모델링**: 부드러운 화이트 털 질감, 갸우뚱한 머리, 초롱초롱한 눈망울(하이라이트 반사광 포함), 촉촉한 코와 혀, 황금 펜던트가 달린 빨간 목걸이, 복슬복슬한 꼬리.
   - **생생한 모션**: 살랑살랑 흔들리는 꼬리 흔들기(Wagging Tail), 갸우뚱거리는 고개 짓, 숨 쉬는 가슴 모션 애니메이션이 실시간으로 구동됩니다.
   - **모드 연동**: 실사 렌더/X-Ray 모드에서 생동감 있게 표시되며, 건축 도면 모드(Blueprint)에서는 도면 가독성을 위해 자동으로 숨겨집니다.

8. **📱 스마트폰 & PC 완벽 반응형 디자인 (High-Readability UI/UX)**
   - **고가독성 모바일 인터페이스**: 작은 화면에서도 글자와 아이콘이 시원하게 잘 보이도록 모바일 타이포그래피(15.5px 타이틀, 12.5~14px 라벨, 17~20px 선명한 아이콘)와 터치 타겟(최소 48px 이상)을 대폭 확대했습니다.
   - **스마트폰 최적화 클린 뷰포트**: 모바일에서는 시야를 가리는 거대한 사이드바와 하단 스펙바를 숨기고 도그하우스 3D 모델을 화면 전체(90% 이상)에 시원하게 배치합니다.
   - **적응형 수직 FOV (Adaptive Camera FOV)**: 화면 비율(Aspect Ratio)에 따라 스마트폰 세로 화면에서는 화각을 넓혀(56°) 도그하우스 전체가 한눈에 잘리지 않고 쏙 들어오도록 자동 조절합니다.
   - **하단 모바일 플로팅 독 & 바텀 시트**: 엄지손가락 한 손 조작에 최적화된 하단 퀵 독(카메라 시점, 지붕 분해, 조명 환경, 상세 제원, 참조 도면)과 스와이프 가능한 바텀 시트 인터페이스를 제공합니다.
   - **PC와 모바일 양방향 실시간 동기화**: 분해 슬라이더, 조명, 시점 등이 PC와 모바일 모든 컨트롤러에서 완벽하게 연동됩니다.

9. **📸 고화질 스냅샷 & 🔊 사운드 이펙트**
   - 원하는 회전 각도에서 `스냅샷` 버튼을 누르면 즉시 고해상도 PNG 이미지로 다운로드됩니다.
   - Web Audio API 기반의 인터랙션 사운드 효과음 내장 (음소거 토글 가능).
